# Dhanshree Nagrale — Portfolio

React + Vite portfolio ready for Vercel.

## Run locally
npm install
npm run dev

## Build
npm run build

## Deploy
Push this folder to GitHub and import the repository into Vercel.

## Personalize
- Replace `public/profile.jpg` with your photo.
- Replace `public/resume.pdf` with your actual resume.
- Update project GitHub links in `src/components/Projects.jsx`.
